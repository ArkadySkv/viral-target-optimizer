# Viral Target Optimizer

Лёгкий математический фреймворк для компьютерного скрининга и оптимизации молекулярных параметров против вирусных белков-мишеней.

## Обзор

Данный проект предоставляет надёжную, готовую к использованию структуру для сопоставления кандидатов из виртуального скрининга с целевыми характеристиками, полученными из литературы по вирусологии. В основе работы лежит метод проекционного градиентного спуска (PGD) с функцией потерь в виде среднеквадратичной ошибки (MSE) для оптимизации ключевых хемоинформатических дескрипторов в нормализованном каноническом координатном пространстве:

- **LogP** (коэффициент распределения / липофильность)
- **MW** (молекулярная масса)

Система функционирует как **сравнительный бенчмаркинговый комплекс**, выполняющий и оценивающий три различных подхода к численной оптимизации. Архитектура проекта строго разделяет входные данные, логику выполнения и вычислительные журналы, что позволяет легко расширять её с использованием продвинутых хемоинформатических пакетов, таких как RDKit.

## Методы оптимизации и математика

Фреймворк моделирует оптимальный выбор параметров лекарственного средства как задачу ограниченной оптимизации (\(\min_{x \in S} f(x)\)) с использованием трёх основных алгоритмов:

### 1. Канонический L-гладкий адаптированный PGD
Нормализует пространство дескрипторов и использует аналитическую константу Липшица \(L = 2.0\) для быстрой сходимости. Данный метод гарантирует сходимость за одну итерацию благодаря теоретически оптимальному выбору шага.

### 2. PGD с ускорением Нестерова (NAG)
Включает инерцию (момент) \(\mu = 0.9\) для улучшения траектории и ускорения на сложных функциях. Этот подход использует концепцию «заглядывания вперёд» при вычислении градиента для ускорения сходимости на плохо обусловленных задачах.

### 3. Эвристический статический PGD
Выступает в роли базового контроля, используя фиксированный шаг без инерции. Этот метод служит точкой отсчёта для оценки эффективности адаптивных и ускоренных методов.

### Ключевые математические особенности

- **Каноническое масштабирование признаков**: Стандартизация пространства исходных дескрипторов в нормализованную систему, где \(x = [\text{LogP}, \text{MW} / 100]\), полностью устраняет плохую обусловленность (\(\kappa = 10000\)), вызванную различиями в масштабах координат.

- **Проекционный градиентный спуск (PGD)**: Основной механизм оптимизирует ограниченные параметры в химических границах (LogP: от -2.0 до 6.0; MW: от 150.0 до 600.0 Да), используя оператор точной евклидовой проекции на прямоугольную область, реализованный через детерминированное клиппирование.

- **Адаптация шага на основе константы Липшица**: Аналитическая оценка матрицы Гессе (\(\nabla^2 f(x)\)) даёт строгую константу Липшица \(L = 2.0\) для масштабированного градиента.

- **Набор для бенчмаркинга**: Среда выполнения систематически сравнивает все три подхода к оптимизации, измеряя скорость сходимости, точность и вычислительную эффективность.

## Будущий план: интеграция с RDKit

В следующих этапах планируется прямая интеграция с экосистемой RDKit для скрининга реальных химических библиотек, включая:

- **Фильтрацию SMILES-строк**: Парсинг и валидация химических структур из SMILES-представлений
- **Динамическое извлечение свойств**: Вычисление MolLogP, MolWt и других дескрипторов «на лету»
- **Проверку структурного сходства с лекарствами**: Применение правила Липински и других фильтров
- **Скрининг реальных химических библиотек**: Проверка тысяч соединений против вирусных мишеней
